🧩 Chọn ghi chú mẫu
☁️ Đồng bộ Google Drive
Đang kiểm tra...
1. Vào console.cloud.google.com/apis/credentials → chọn project (tạo mới nếu chưa có).
2. Bấm + CREATE CREDENTIALS → OAuth client ID. Nếu được hỏi, bấm Configure consent screen → chọn External → điền tên app → lưu → quay lại.
3. Ứng dụng chọn Web application. Ở Authorized JavaScript origins bấm + ADD ORIGIN và dán đúng 2 dòng:
https://tanvinh9198-cyber.github.io
https://tanvinh9198-cyber.github.io/ghi-chu-note
4. Bấm CREATE → copy đoạn Client ID dạng xxxx.apps.googleusercontent.com dán xuống ô dưới.
5. Vào trang consent screen → mục Audience → phần Test users → bấm + ADD USERS → thêm email Google của mày (bắt buộc, nếu không sẽ báo "access blocked").
Note được lưu trong appDataFolder của Drive — một thư mục ẩn, chỉ app này thấy được, không xuất hiện trong Drive của mày và không ai khác đọc được. Nội dung note không gửi đi đâu ngoài Google Drive.
